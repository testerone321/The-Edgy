# The Edgy

An app that takes care of edging sessions for The Handy, with configurable speeds, patterns, and evil surprises to make your edging experience more intense and unpredictable.

## Notes

- The App requires a compatible The Handy for production use
- Debug mode (`DEBUG_MODE=true`) uses a mock device controller for testing
- Session state is managed entirely in memory (sessions are lost on server restart)

## Quick Start

```bash
# Install dependencies
npm run install-all

# Run development servers
npm run dev

# Run development servers in debug mode
npm run dev:debug
```
